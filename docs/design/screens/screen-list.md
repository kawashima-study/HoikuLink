# 画面一覧（公開版・修正版 第2版）

- 作成日：2026-10-07
- 第2版の変更：連絡帳一覧・詳細を、保育士連絡帳・保護者連絡帳の両方を扱う画面に統合
- 画面の項目の細部は、画面の実装の前（2026-10-30）までに決める

| 機能ID | 機能名 | 利用者区分 | 概要 | URL | 備考 |
|---|---|---|---|---|---|
| SCR-T-001 | ログイン | 教員 | 利用者認証を行う画面 | `/login` | ログイン後、初期パスワードなら SCR-T-009、そうでなければ SCR-T-008 へ |
| SCR-T-008 | 園の選択 | 教員 | 所属する園から、操作する園を選ぶ画面 | `/nurseries/select` | 所属が1園だけなら表示せずに自動で選択。閉園・退職した園は表示しない |
| SCR-T-009 | パスワード変更 | 教員 | パスワードを変更する画面 | `/password` | 初期パスワードの間は、この画面以外に進めない（ADR-57） |
| SCR-T-002 | トップ | 教員 | 閲覧範囲の園児と最新の連絡帳を表示する画面 | `/top` | 一般は担当園児、副主任以上は全園児。見てよい園児の直近7日間の連携事項を新しい順に表示（公開版はテストデータ。入力画面は追加要件。ADR-93） |
| SCR-T-003 | 園児一覧 | 教員 | 園児一覧を表示し、対象園児を選択する画面 | `/children` | 連絡帳作成・連絡帳一覧画面へ遷移 |
| SCR-T-004 | 連絡帳作成 | 教員 | 保育士連絡帳を新規作成する画面 | `/diaries/new` | 園児一覧画面から遷移。画像の追加を含む |
| SCR-T-005 | 連絡帳一覧 | 教員 | 保育士・保護者が作成した連絡帳を、まとめて検索・一覧表示する画面 | `/diaries` | 一覧の各行に種類（保育士／保護者）を表示。1ページ50件、最大40ページ |
| SCR-T-006 | 連絡帳詳細（保育士作成） | 教員 | 保育士連絡帳の詳細を表示し、画像の削除・連絡帳の削除をする画面 | `/diaries/teacher/:teacherDiaryId` | 編集画面へ遷移可能 |
| SCR-T-010 | 連絡帳詳細（保護者作成） | 教員 | 保護者連絡帳の詳細を表示し、画像の削除・連絡帳の削除をする画面 | `/diaries/parent/:parentDiaryId` | 文章の編集はできない |
| SCR-T-007 | 連絡帳編集 | 教員 | 保育士連絡帳を編集する画面 | `/diaries/teacher/:teacherDiaryId/edit` | 他の人が先に更新していたら「他の人が更新しました」と表示（409） |
| SCR-T-012 | 園の管理（ロック解除） | 教員（園長・主任） | ロック中のアカウントを一覧表示し、解除する画面 | `/management/locked-accounts` | `ACCOUNT_UNLOCK` を持つ役職だけに表示 |

SCR-T-011（保護者連絡帳詳細）は、第2版でSCR-T-010（連絡帳詳細〔保護者作成〕）に整理したため欠番。

## 画面に共通の動き

| 動き | 内容 |
|---|---|
| Polling | 25秒ごとに状態を確認。401ならログイン画面、403なら園の選択画面へ |
| 無操作15分 | サーバーが401を返したらログイン画面へ（警告ダイアログは追加要件） |
| 権限のない操作 | 権限のないボタンは表示しない。APIが403を返したら「表示する権限がありません」と表示しトップへ |
| エラーの表示 | APIのエラー（RFC 9457）の `title` を表示し、`code` で処理を分ける（例：409なら読み込み直しを促す） |
| ログアウト | ページを完全に読み込み直してログイン画面へ（bfcache対策） |

## 修正点の一覧

| 版 | 変更 | 理由 |
|---|---|---|
| 第1版 | 園の選択（SCR-T-008）を追加 | 2つの園を兼務する保育士がログイン後に選ぶ（ADR-41） |
| 第1版 | パスワード変更（SCR-T-009）を追加 | 初期パスワードの強制変更（ADR-57） |
| 第1版 | 園の管理（SCR-T-012）を追加 | ロック中のアカウントの解除（ADR-55） |
| 第2版 | 連絡帳一覧を、保育士・保護者の両方を検索する画面に | 両方をまとめて確認できるようにする（ADR-89） |
| 第2版 | 連絡帳詳細を、保育士作成・保護者作成の2画面に（どちらも画像の削除が可能） | 種類によって表示する項目と操作（編集の可否）が違うため |
